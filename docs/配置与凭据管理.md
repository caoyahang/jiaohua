# 配置与凭据管理

> 项目全部命令、环境变量、账号凭据的**管理入口**。
> 铁律（总纲 §3）：**凭据唯一存放处是 `.env`（不入 git）；本文档只登记"有什么、在哪改、改了影响什么"，严禁抄录真实密码。**
> 运维操作流程见 `docs/操作手册.md`；脚本详情见 `scripts/README.md`。

## 1. 凭据与环境变量清单

存放：项目根目录 `.env`（从 `.env.example` 复制生成；`.env` 已被 .gitignore 忽略）。
读取方：`docker-compose.yml`（注入容器）、`services/api/`（os.getenv）、`data/collector/`。

| 变量 | 用途 | 读取方 | 修改影响面 |
|---|---|---|---|
| `DB_PASSWORD` | PostgreSQL `ai_admin` 账号密码 | compose → postgres 容器 + `DATABASE_URL` | 改后需 `make down && make up` 重建 PG 容器（首次初始化后改密码还需进库 ALTER USER） |
| `DATABASE_URL` | PG 连接串（含上面的密码） | `services/api/db/connections.py` | 与 `DB_PASSWORD` 必须同步改 |
| `TDENGINE_URL` | TDengine 连接串 | `connections.py`、collector | 改后重启 api/collector |
| `REDIS_URL` | Redis 连接串 | `connections.py` | 改后重启 api |
| `JWT_SECRET_KEY` | JWT 签名密钥 | `core/security.py` | **改后全部已签发 token 立即失效**，所有人需重新登录 |
| `JWT_EXPIRE_MINUTES` | token 有效期（默认 480 分钟） | `core/security.py` | 重启 api 生效 |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 单管理员登录账号 | `core/security.py` | 改后重启 api 生效；代码默认值 `admin/admin123` 仅开发用，**部署前必须改** |
| `OPC_UA_ENDPOINT` | DCS OPC UA 地址 | `data/collector/opcua_client.py` | 改后重启 collector |
| `MODBUS_HOST` / `MODBUS_PORT` | 振动采集 Modbus 地址 | `data/collector/modbus_client.py` | 改后重启 collector |
| `MLFLOW_TRACKING_URI` | MLflow 跟踪服务地址 | 各 train.py、`scripts/model_retrain.sh` | MLflow server 未部署前仅占位 |
| `BLEND_PREDICTOR_MODE` | 质量预测后端：empirical / ml / auto（默认 auto） | `services/api/routes/blend.py` | 重启 api 生效 |
| `BLEND_ERROR_THRESHOLD` / `BLEND_BUFFER_SIZE` | 增量学习触发阈值（方案§4.1.7） | `routes/blend.py` | 重启 api 生效 |
| `LOG_LEVEL` | 日志级别 | `services/api/main.py` | 重启 api 生效 |

## 2. 常用命令

### 服务编排（Makefile）

| 命令 | 作用 |
|---|---|
| `make up` / `make down` | 启动 / 停止全部服务（docker compose） |
| `make init-db` | 快照建表（仅开发调试用；正式部署走 `scripts/deploy.sh` 增量迁移） |
| `make test` | 跑全部 pytest |
| `make check` | **提交前评审门禁**（pytest + 红线 grep + OpenAPI 新鲜度；pre-commit 钩子同款） |
| `make check-full` | 追加四个前端工程 tsc 类型检查 |
| `make logs` / `make ps` | 看日志 / 看服务状态 |

### 脚本（scripts/）

| 命令 | 作用 |
|---|---|
| `bash scripts/deploy.sh` | 正式部署（含 migrations 增量迁移） |
| `bash scripts/backup.sh` | 备份（破坏性操作有人工确认开关） |
| `bash scripts/model_retrain.sh` | 模型重训管道（train → evaluate → MLflow staging） |
| `python scripts/export_openapi.py` | 重新导出 `frontend/shared/openapi.json`（改了路由必跑） |

### 本地开发

```bash
# 后端（依赖装入 .venv，重依赖懒加载，未装也能跑轻量单测）
python -m venv .venv
.venv/Scripts/python -m pip install fastapi "uvicorn[standard]" pytest httpx numpy pandas scikit-opt shap
.venv/Scripts/python -m uvicorn services.api.main:app --reload --port 8000

# 前端（任一模块，以 blend_ui 为例）
cd frontend/blend_ui && npm install && npm run dev
```

登录获取 token：`POST /auth/login`，用户名密码即 `.env` 的 `ADMIN_USERNAME` / `ADMIN_PASSWORD`。

## 3. 部署前必改清单（安全）

- [ ] `DB_PASSWORD`（两处：变量本身 + `DATABASE_URL` 内嵌密码）
- [ ] `ADMIN_PASSWORD`（代码默认 `admin123` 是公开值）
- [ ] `JWT_SECRET_KEY`（代码默认 `dev-only-insecure-secret` 是公开值）
- [ ] `.env` 权限收敛（生产机 `chmod 600 .env`），不截图、不发群、不进文档

## 4. 禁止事项（总纲 §3 红线）

- 密码/密钥**禁止**出现在：`config/*.yaml`、任何 `.md`、代码注释、git 历史。
- 新增凭据类配置：只加 `.env` 变量 + 在 `.env.example` 登记占位（`change_me_xxx`）+ 在本文档 §1 表格登记。
- 怀疑泄露：立即轮换对应凭据（按 §1 影响面列的步骤），不要只删文件——git 历史还在。
